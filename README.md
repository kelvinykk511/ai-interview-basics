# AI Engineer Interview Basics（新手向）

給 Java 後端轉型 AI 工程的面試溫習庫。**從零開始**，先搞懂名詞與直覺，再碰模型細節。

## 目錄（建議順序）

| 目錄 | 主題 |
|------|------|
| `01-ml-basics/` | 機器學習是什麼、訓練/推理 |
| `02-neural-nets/` | 神經網絡直覺（不先推公式） |
| `03-llm-basics/` | 大語言模型、Token、上下文 |
| `04-prompt-rag/` | Prompt、RAG（檢索增強） |
| `05-mlops/` | 部署、監控、數據（工程向） |
| `06-python-stack/` | 常見工具棧（PyTorch 等名詞） |
| `07-system-design/` | AI 應用怎麼設計（後端視角） |
| `sessions/` | 每日短溫習 |

## 約定

- 繁體中文、白話優先
- 每個主題：一句人話 → 面試怎麼答 → 一個小問題
- 先當「懂概念的工程師」，再補數學
